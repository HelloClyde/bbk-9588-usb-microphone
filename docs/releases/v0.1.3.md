# v0.1.3

First public source release of the experimental BBK 9588/JZ4730 USB
microphone stack.

## Included

- `9588UsbMic.bda`: device application with immediate PCM capture, live
  waveform, CDC ACM transport, and touch/Esc exit.
- `9588UsbMicSetup.exe`: Windows x64 bridge installer. It installs the bridge,
  can download the original VB-CABLE driver package from VB-Audio, preserves
  existing default playback endpoints, and selects `CABLE Output` as the
  default recording endpoint.
- `SHA256SUMS.txt`: SHA-256 digest for both downloadable binaries.

## Hardware status

The JZ4730 SDK capture to EP2 Bulk IN to Windows PCM path has been verified on
real hardware at 16 kHz, signed 16-bit, mono. Frame gaps, checksum failures,
and underruns were zero in the recorded 15-second baseline.

USB Mass Storage hot restoration is not supported. Disconnect USB before
exiting the BDA, then restart the 9588 before reconnecting it for storage.

## Windows notice

The outer installer is not Authenticode-signed, so Windows may show a
SmartScreen warning. VB-CABLE is not bundled in this repository; when selected,
the installer downloads the original signed package from VB-Audio and verifies
its pinned SHA-256 hash.
