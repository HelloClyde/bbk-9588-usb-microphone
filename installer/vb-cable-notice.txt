Distribution note
-----------------

VB-Audio's current website permits bundling under its Donationware conditions,
but the package readme also says integration into another installer requires
the author's agreement. This project therefore downloads the package directly
from VB-Audio for development builds. Obtain written redistribution permission
or the appropriate volume license before shipping an offline commercial
installer that embeds the package.

The 9588 USB Microphone uninstaller leaves VB-CABLE installed because it is a
shared audio driver that may be used by other applications. It can be removed
separately with the original VB-CABLE setup program.
